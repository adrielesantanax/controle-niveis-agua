# Controle de Níveis de Água

## Descrição
Este projeto simula o monitoramento de um reservatório de água, exibindo mensagens de alerta coloridas de acordo com o nível da água.

## Tecnologias utilizadas
- Python
- Biblioteca Colorama


## Níveis do reservatório

<ul>
  <li><strong style="color: red;">Nível 1:</strong> <span style="color: red;">Muito baixo (crítico) — Vermelho</span></li>
  <li><strong style="color: #D4A000;">Nível 2:</strong> <span style="color: #D4A000;">Baixo — Amarelo</span></li>
  <li><strong style="color: green;">Nível 3:</strong> <span style="color: green;">Médio — Verde</span></li>
  <li><strong style="color: #00BFCB;">Nível 4:</strong> <span style="color: #00BFCB;">Alto — Ciano</span></li>
  <li><strong style="color: blue;">Nível 5:</strong> <span style="color: blue;">Muito alto (alerta) — Azul</span></li>
</ul>


## Como executar
1. Instale o Python.
2. Instale a biblioteca com o comando: `pip install -r requirements.txt`
3. Execute o programa com o comando: `python controle_agua.py`

Praticar o uso de listas, funções e bibliotecas em Python.
